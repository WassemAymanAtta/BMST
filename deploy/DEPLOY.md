# نشر موقع BMST — الدليل العملي

## الخلاصة

الموقع فيه جزء PHP (حفظ الطلبات)، فمحتاج استضافة تدعم **PHP 8.0 أو أحدث**.
الأنسب لك: **دومين `.com` + استضافة PHP مشتركة**. التكلفة التقريبية:

| البند | السعر التقريبي |
| --- | --- |
| دومين `.com` | $10–15 / سنة |
| استضافة PHP مشتركة | $25–45 / سنة |

## 1) اختيار الاستضافة

**الخيار الأول (الموصى به): Hostinger — Premium Web Hosting**
- سعره غالباً أقل من $3/شهر مع عقد سنة، وبيقبل طرق دفع محلية في مصر.
- لوحة `hPanel` سهلة، PHP 8.2/8.3، SSL مجاني، وFile Manager مدمج.

**بديل موثوق: Namecheap — Stellar Hosting**
- تقريباً $2/شهر + الدومين منفصل. لوحة cPanel كلاسيكية ودعم جيد.

تأكد إن الباقة فيها: **PHP 8.0+**، **مساحة كتابة**، و**Free SSL**.

## 2) الدومين

- `.com` أو `.org` أرخص وأسهل من `.eg` (اللي بيتطلب أوراق تسجيل من مصر).
- أسماء مقترحة للبحث عن توفرها: `bmst-team.com`، `bmstbanimazar.com`، `bmstcommunity.org`.
- لو الدومين مش متاح، جرّب تضيف `eg` أو `club` في النهاية.

## 3) تجهيز الملفات

داخل المجلد ده هتلاقي `bmst-site.zip`. لو عدّلت أي حاجة في الكود بعد كده، أعد عمله من جوه `D:\BMST`:

```powershell
cd D:\BMST
Compress-Archive -Path index.html,style.css,script.js,.htaccess,api,images,data -DestinationPath deploy\bmst-site.zip -Force
```

> الملفات المستبعدة قصداً: `config.local.php` (خاص/معطل)، `test-whatsapp.php`، `README.md`، مجلد `.git`، وأي بيانات اختبار في `data/`.

## 4) الرفع

1. ادخل لوحة الاستضافة → **File Manager** → افتح `public_html` (أو `wwwroot`).
2. امسح أي ملفات افتراضية زي `default.html`.
3. ارفع `bmst-site.zip` واضغط **Extract** جوه `public_html`.
4. لازم يبقى الهيكل كده:
   ```
   public_html/
     index.html
     style.css
     script.js
     .htaccess
     api/
       application.php
       config.php
       whatsapp.php
     images/
       BMST.jpeg
       team.jpeg
       QR.png
     data/
       .htaccess
       .gitkeep
   ```
5. في File Manager: افتح خصائص مجلد `data` واتأكد إن الصلاحيات `755`. لو الطلبات مبتتسجلش، جرّب `777`.

## 5) التجهيز النهائي

- فعّل **SSL مجاني** من اللوحة (AutoSSL / Let's Encrypt) وافتح الموقع بـ `https://`.
- في لوحة الاستضافة، اتأكد إن إصدار PHP = **8.2** أو **8.1**.
- اربط الدومين: في إعدادات الدومين حط `www` وبدون `www` على نفس المسار، واستخدم redirect من `http` لـ `https`.

## 6) اختبار بعد النشر

1. افتح `https://دومينك.com` — لازم الصفحة تظهر كاملة بالصور.
2. جرّب زر **EN / عربي** وزر المظهر الداكن.
3. املأ نموذج التواصل وابعت:
   - لازم يتفتح واتساب برسالة جاهزة لرقم `+20 112 599 3315`.
   - اضغط Send في واتساب → الرسالة توصلك.
   - بعدها لازم يظهر «تم إرسال رسالتك بنجاح».
4. جرّب طلب الانضمام كمان.
5. اتأكد إن الحفظ شغال: حمّل `data/applications.php` عبر FTP أو افتحه من File Manager — هتلاقي سطر JSON لكل طلب.
6. جرّب الموقع على موبايل (RTL بالعربي).

## 7) تخصيصات لازم تراجعها قبل النشر

| المكان | اللي اتعدّل |
| --- | --- |
| `index.html` → `<body data-whatsapp="...">` | رقم واتساب المسؤول (digits فقط بالكود الدولي) |
| `index.html` → قسم التواصل والفوتر | رقم الهاتف الظاهر + الإيميل + فيسبوك |
| `index.html` → قسم الدعم | بيانات إنستاباي / فودافون كاش / رمز QR |
| `api/application.php` | حد السبام (6 طلبات / 10 دقائق) |

## 8) مشاكل شائعة

| المشكلة | السبب والحل |
| --- | --- |
| صفحة بيضاء / 500 | إصدار PHP أقل من 8.0 — غيّره للـ 8.2 من اللوحة. |
| الرسالة مش بتتسجل | صلاحيات `data/` — اضبطها 755 أو 777. |
| واتساب مش بيفتح | المتصفح منع النوافذ المنبثقة — استخدم الزر الأخضر «فتح واتساب» تحت الفورم. |
| الخطوط شكلها غريب | تأكد إن الاستضافة مش بتمنع تحميل Google Fonts / Font Awesome. |
| الرسالة وصلت مكررة | تأكد إن `enabled` في `api/config.local.php` لسه `false` (متضمنش في الحزمة أصلاً). |

## 9) لو حابب تستخدم Netlify / Vercel بدل كده

الموقع كـ Frontend بس هيشتغل فوراً، بس حفظ الطلبات محتاج تحويل `api/application.php` لـ Serverless Function وتخزين خارجي. قوللي وأعمل لك النسخة دي.
