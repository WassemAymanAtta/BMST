# نشر BMST على Netlify — مجاني 100%

النسخة دي **من غير PHP نهائياً**. الاستضافة + SSL + رابط `netlify.app` مجانية، واستقبال الطلبات بيتم عبر `Netlify Forms` (مجاني لحد 100 طلب/شهر). واتساب شغال زي ما هو من غير أي API.

## هتدفع إيه؟ صفر.
| البند | الخطة المجانية |
| --- | --- |
| الاستضافة | مجانية (100GB bandwidth/شهر) |
| SSL | مجاني وتلقائي |
| الرابط | `https://اسمك.netlify.app` مجاني |
| الفورمات | 100 تسليم/شهر |
| الدومين الخاص | مجاني لو حطيته بعدين |

## الخطوات (5 دقائق)

1. افتح **https://www.netlify.com** واعمل Sign up مجاني (بريد أو GitHub).
2. افكّ ضغط `bmst-netlify.zip` في أي مجلد على الكمبيوتر.
3. افتح **https://app.netlify.com/drop** واسحب المجلد كله وأفلته في الصفحة.
4. Netlify هينشر الموقع فوراً ويديك رابط عشوائي زي `https://random-name-123.netlify.app`.
5. من **Site configuration → Site details → Site name** غيّر الاسم لـ `bmst` (أو `bmst-team`) عشان تبقى:
   ```
   https://bmst.netlify.app
   ```
6. من القائمة: **Forms** — لازم تلاقي فورمين باسماء `join` و `contact`. لو ما ظهروش، تأكد إن `index.html` فيه `data-netlify="true"` جوّه كل `<form>` (موجود في النسخة دي).

## تجربة سريعة

1. املأ فورم التواصل وابعت.
2. لازم يتفتح واتساب برسالة جاهزة لرقم `+20 112 599 3315` → اضغط Send.
3. روح **Netlify → Forms → contact → Submissions** — هتلاقي الطلب هناك بالاسم والإيميل والموضوع والرسالة.
4. جرّب فورم الانضمام كمان، وهتلاقيه تحت `join`.

## إشعارات إضافية (اختياري)
من **Forms → Form settings → Email notifications** تقدر تحط بريدك عشان يوصلك نسخة لما حد يبعت — ده كـ backup لو واتساب مش متاح. مجاني كمان.

## الحماية من السبام
- فيه حقل مخفي `website` (honeypot) جوّه الفورمين — البوتات بتعبّاه وNetlify بيتجاهل الطلب.
- كمان Netlify فيه فلتر سبام مدمج في الخطة المجانية.

## تحديث الموقع بعدين
الأسهل: اعمل تعديل في الملفات،然后把 المجلد كله على Netlify Drop تاني (هيعمل Site جديد). الأفضل: ارفع المجلد على GitHub repository جديد واربطه بـ Netlify من **Add new site → Import from Git** — بعدها أي `git push` بينشر تلقائياً.

## لو زادت الطلبات عن 100/شهر
الواتساب هيشتغل عادي لأنه من المتصفح، بس الحفظ في Netlify Forms هيقف. الحلول:
- ارفع لـ Pro ($19/شهر)، أو
- حوّل لـ `Cloudflare Pages + D1` (مجاني بس فوق بكثير) — قوللي وأجهزه لك.
